PySymGym
========

PySymGym is a Python gym to train AI-powered assistants that guide symbolic
machines (symbolic execution engines).

The repository contains the Python agent (``AIAgent/``), the symbolic-machine
game servers under ``GameServers/`` (git submodules), and command-line tools
under ``tools/``.
